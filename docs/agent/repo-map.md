# Repository map

- `src/extension/`: unpacked MV3 extension (planned).
- `src/cast/`: shared sender/session logic (planned).
- `src/shared/`: media validation/extraction (planned).
- `scripts/`: safe reconnaissance, fixture server, build/validation (planned).
- `tests/`: deterministic unit/browser fixtures (planned).
- `docs/agent/`: concise evidence, decisions, and reproducible handoffs.
- `artifacts/`, `.local/`: ignored local evidence; never commit credentials/media.
